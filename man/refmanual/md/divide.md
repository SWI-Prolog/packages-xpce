# class divide {#class-divide}

Arithmetic expression.  _/_ evaluates both its `binary_expression-left`
and `binary_expression-right` operands and returns the quotient.  The
quotient is an integer only if the division is exact: `7/2` is 3.5.
Use class int_divide (`//`), round or floor where an integer is needed.
Dividing by zero yields infinity.

@see class binary_expression
@see class plus
@see class times
@see class int_divide
